## 正とするドキュメントの優先順位

本ディレクトリのドキュメントは**2026-08-01クライアントMTGより前に書かれたドラフト**であり、
確定事項と食い違う記述が残っている。矛盾がある場合は以下の順に「正」とする。

1. **ルートの `要件定義書.md`（v2.1）** — 確定した機能要件・スコープ・確定値
2. **`docs/議事録_2026-08-01_クライアントMTG.md`** — 最新のクライアント決定事項
3. `AGENTS.md` / `.claude/skills/hotel-revenue-rules/SKILL.md` — 開発ルール・ドメイン確定値

## 更新ルール

- クライアント決定事項が増えたら、まず議事録・ルート要件定義書を更新し、本README の読み替え表に追記する
- 本ディレクトリの各ドキュメントを個別に書き換える場合は、相互参照（13→15→16等）が多いため関連ファイルもセットで更新する
