# 改善計画（総点検 2026-09-11 の所見に基づく）

総点検で洗い出した所見を、実装順・担当領域・受け入れ条件つきのタスクに落としたもの。
各タスクの ID はコミット件名の末尾に付ける（例 `fix(backend): アクセストークンに type クレームを追加 (S-1)`）。

- 前提: AGENTS.md の必須ルール（認証／テナント分離／zod／監査ログ／`config` 経由の環境変数／マイグレーションのコミット）は全タスクに適用する。
- 検証: 各 Wave の終わりに `pnpm --filter './*' type-check` → `pnpm --filter './*' lint` → `pnpm --filter backend test` → 両ビルド → ローカル PostgreSQL での migrate/seed/API 疎通 → ブラウザ操作を通す。
- 方針の変更点（要確認）: **デモモードを opt-in（`NEXT_PUBLIC_DEMO_MODE=true` のときだけ有効）に変える**。既存のデモ環境（hotel-price.vercel.app）を維持するには Vercel の環境変数に `NEXT_PUBLIC_DEMO_MODE=true` を設定する必要がある。
