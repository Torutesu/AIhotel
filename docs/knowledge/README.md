# 知識ベース（レベニューマネジメントの基礎）

このディレクトリの Markdown が、チャット応答と AI まとめの「根拠」になります（`backend/src/services/knowledge/`）。

- 1ファイル = 1テーマ。`##` / `###` 見出しごとに1チャンクとして検索・引用されます。見出しは「その節だけ読んで意味が分かる」名前にしてください。
- 先頭の `# 見出し` がドキュメント名になります。ファイル名の数字は表示順です。
- 回答は必ず該当章を引用します。ここに書いていないことは「基礎資料に記載なし」と答えます。
- ホテル固有のルール（団体の扱い、フロア価格など）はここではなく、各ホテルの設定・イベント・採否理由に入れてください。テナント共通の基礎だけをここに置きます。
- 反映は backend の再起動（または `POST /api/v1/knowledge/reload`、ADMIN）で行われます。置き場所は `KNOWLEDGE_DIR` で変更できます。
