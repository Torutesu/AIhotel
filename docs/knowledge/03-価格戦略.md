# 価格戦略とランク運用

## 料金ランクの考え方
料金ランクは需要の強さに対応する価格の段階であり、ランク表そのものが価格戦略の骨格である。基準ランクは予測稼働率から機械的に決まり、そこから戦略重みと競合で上下させる。ランク表の価格刻みが粗いと、推奨の粒度も粗くなる。

## 稼働率重視・ADR重視・競合追従の意味
稼働率重視は「収益を少し犠牲にしても客室を埋める」立場で、朝食・館内売上・口コミの積み上げを重視するホテル向き。ADR重視は「レートの整合性を守り、値崩れを避ける」立場。競合追従は自社の需要推定に自信が持てないときのヘッジであり、競合が売止めしている日は追従の意味が変わる。重みの合計は100%で、迷ったら 40/40/20 から始めて実績で調整する。

## ガードレール
1日の最大変動幅は、予測の外れによる乱高下を防ぐ。最小ランクはブランド価値の下限、最大ランクは需要の天井。ガードレールで丸められた推奨は、理由分解に「ガードレール」として表示される。

## 推奨の採否
推奨を採用しない場合は理由を残す。理由は次回の学習材料になり、同じ理由が繰り返されれば習慣として先回りされる。「なんとなく」の上書きは学習を汚すので避ける。
