# 需要予測と予約ペース

## 予測の3つの柱
需要予測の説明力は、予約ペース（OTB＝その時点の予約積上）、曜日と季節性（同曜日平均・前年同日）、イベントと祝日の順に大きい。外部要因（天候・競合）はその次であり、ペースが動く前に先回りするための事前情報として扱う。

## ペースの見方
同じリードタイム（宿泊日までの残日数）で過去の同曜日がどれだけ積み上がっていたか（典型積上率）と比べる。典型より速ければ最終稼働は高く着地し、遅ければ低く着地する。リードタイムが短いほどペースの情報量は大きく、遠い日ほど季節性の比重が大きい。

## 予測の外れ方を見る
毎日の答え合わせで「どの要因が効いていた日に、どちら向きに外れたか」を見る。同じ要因で同じ向きに外れ続けるなら、その要因の係数がずれている。1日の外れで係数を大きく動かさず、サンプルが増えるほど実績寄りに寄せる（縮小推定）。

## 信頼区間の使い方
予測は点ではなく幅で読む。リードタイムが長いほど幅は広い。幅が広い日ほど、価格を一度に大きく動かさず、変動幅のガードレールの中で段階的に動かす。
