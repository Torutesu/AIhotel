# 基礎指標（稼働率・ADR・RevPAR）

## 3つの指標の関係
稼働率（OCC）は販売客室数÷販売可能客室数。ADR は客室売上÷販売客室数。RevPAR は客室売上÷販売可能客室数で、RevPAR = OCC × ADR。レベニューマネジメントの最終目標は RevPAR（およびそれに付随する総売上）の最大化であり、稼働率や ADR の単独最大化ではない。

## 稼働率とADRのトレードオフ
価格を下げれば稼働率は上がるが ADR は下がる。RevPAR が最大になるのは、需要の価格弾力性が 1 になる点。需要が客室数を超えているとき（満室が見える日）は値上げしても RevPAR は下がらないため、満室予測の日は ADR 側に寄せる。需要が弱い日は値下げしても埋まらないことが多く、RevPAR は基準価格付近が最適になりやすい。

## 需要レベル A〜E の読み方
本システムでは予測稼働率を A（90%超）、B（80%超）、C（65%超）、D（50%超）、E（それ以下）に分ける。A・B は「売り切りと単価」、D・E は「需要喚起と最低価格の維持」が論点になる。C は戦略重みの影響を最も受ける帯である。
