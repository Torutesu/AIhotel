# 外部要因の見方

## 祝日・連休
連休前夜（翌日が休みの平日）は最も需要が強く、連休最終夜（翌日が平日）は弱い。3連休以上の中日は強い。土日だけの週末は曜日パターンに含まれるので、祝日を含む連休だけを外部要因として扱う。GW・お盆・年末年始は祝日の並びに関係なく固定期間として見る。

## イベント
会場の収容人数、ホテルからの距離、宿泊率で影響を見積もる。承認していないイベント候補は予測に使わない。前年の実績で曜日と祝日で説明できない上振れがあれば、年次イベントの可能性がある。

## 天候
天候は直前（3日以内）の需要にのみ効く。都市部のビジネスホテルではほぼ効かず、リゾート・観光地では効く。雨予報の日は当日の飛び込みが減る。天候の係数は実績で学習させ、効かないなら 0 に落とす。

## 競合価格と売止め
競合価格は需要の指標ではなく、自社価格の相対位置の指標として使う。自社が競合中央値より高ければ予約ペースが落ちやすい。競合の売止めが増えている日はエリア全体が逼迫している可能性があるが、団体の売止めは実需ではないので除外する。
