# 日次運用の型

## 毎朝5分の手順
1. 今日決めるべき日（推奨と現在のランクが違う日を期待増収額順に見る）を上から処理する。
2. 昨日からの変化を見て、動いた理由が納得できるか確認する。納得できなければ理由を書いて上書きする。
3. 昨日の答え合わせを見て、外れた要因と係数の修正方向を確認する。
4. 新しく分かった外部要因（イベント、工事、団体）を登録する。

## 判断に迷ったとき
需要レベルが A・B なら「下げない」を基本にし、D・E なら「最低価格を割らない範囲で需要喚起」を基本にする。C は戦略重みどおりで良い。予測の信頼区間が広い日は動かす幅を小さくする。

## 月次の振り返り
推奨の採用率、採用日と上書き日の RevPAR 差（同じ需要レベル帯で比較）、リードタイム別の予測精度を見る。上書きが多い要因は係数か運用ルールのどちらかがずれている。
