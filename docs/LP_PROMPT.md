# ホテル収益管理システム - LP作成用プロンプト

## 📋 アプリケーション概要

### プロダクト名
**ホテル収益管理システム（Hotel Revenue Management System）**

### コンセプト
AIを活用したホテルの収益管理・価格最適化システム。リアルタイムの需要予測、競合分析、動的価格設定により、ホテルの収益を最大化します。

---

## 🎯 ターゲットユーザー

- **ホテル経営者・マネージャー**
- **収益管理（RM）担当者**
- **営業・マーケティング担当者**
- **フロントマネージャー**
- **ホテルチェーン運営会社**

---

## ✨ 主な機能・特徴

### 1. 📊 リアルタイムダッシュボード
- **KPI進捗状況の可視化**: 室料売上、販売室数、ADR、稼働率、RevPAR、宿泊人数、DOR、客単価をリアルタイムで表示
- **AI予測値の表示**: 月末時点での予算達成率をAIが予測
- **前年比・予算比比較**: 累計進捗と年度累計を自動比較
- **アラート機能**: 目標値未達や異常値を自動検知して通知
- **AI解説**: データの傾向をAIが自動分析し、わかりやすく解説

### 2. 💰 ダイナミックプライシング
- **AI需要予測に基づく価格最適化**: 需要レベル（A〜E）を自動判定し、最適価格を提案
- **リアルタイム価格調整**: 日別・時間別に価格を自動調整
- **セグメント別価格設定**: 1名〜6名まで人数別に最適価格を設定
- **価格戦略の選択**: バランス型、稼働率優先、ADR優先から選択可能
- **価格変更履歴の追跡**: 過去の価格変更を記録・分析
- **重み付け設定**: 稼働率、ADR、競合価格の重要度をカスタマイズ

### 3. 📈 日別分析
- **日別パフォーマンス分析**: 日次データの詳細分析とトレンド可視化
- **ブッキングカーブグラフ**: 予約状況の時系列可視化で需要パターンを把握
- **曜日別パフォーマンス分析**: 曜日ごとの傾向分析で最適な価格設定を支援
- **競合ホテルとの価格比較**:
  - 複数人数（1名〜6名）の同時比較
  - 複数ホテル（A、B、Cホテル）の同時比較
  - 日別価格推移グラフで視覚的に比較
  - 価格差の可視化（バーチャート）
  - 曜日別競合価格比較テーブル

### 4. 🔍 各種分析
- **セグメント別クロス分析**: 顧客セグメントごとの収益性を分析
- **需要予測分析**: AIによる将来の需要予測
- **市場トレンド分析**: 市場動向を把握し、戦略立案を支援

### 5. 📄 レポート機能
- **詳細レポート生成**: カスタマイズ可能なレポート作成
- **PDF/Excelエクスポート**: データを外部ファイルとして出力
- **カスタムレポート設定**: 必要な指標を自由に組み合わせ

### 6. 🎯 キャンペーン管理
- **キャンペーン参画データ管理**: OTAキャンペーンの参画状況を一元管理
- **キャンペーン効果分析**: キャンペーンによる予約増加や収益への影響を分析
- **OTA連携管理**: 楽天トラベル、Booking.com、一休.comなどの連携管理

### 7. 🤖 AI機能
- **AI解説**: ダッシュボードのデータを自動分析し、わかりやすい解説を提供
- **AI要約**: 収益状況を要約し、重要なポイントを抽出
- **チャットインターフェース**: AIに質問して、データの意味や改善策を相談可能

---

## 💡 主な価値提案（USP）

1. **AIによる自動最適化**: 人手では難しい複雑な需要予測と価格設定をAIが自動実行
2. **リアルタイム分析**: 最新のデータを常に反映し、迅速な意思決定を支援
3. **競合分析**: 複数の競合ホテルと複数人数での価格比較が一度に可能
4. **収益最大化**: 適切な価格設定により、稼働率とADRのバランスを最適化
5. **業務効率化**: 手作業の価格設定やレポート作成を自動化し、時間を節約
6. **データドリブンな意思決定**: 感覚ではなく、データに基づいた経営判断を実現

## 🎨 LP作成時の注意事項

### 1. デザイン面
- **プロフェッショナルな印象**: ホテル業界向けなので、信頼感のあるデザインを心がける
- **データ可視化の重要性**: グラフやチャートを多用し、データの見やすさを重視
- **モダンなUI**: Next.js 15、React 19、Tailwind CSS 4を使用した最新技術スタックをアピール
- **レスポンシブ対応**: デスクトップ、タブレット、スマートフォンで快適に閲覧できること
- **カラースキーム**: ホテル業界に適した落ち着いた色合い（紺、グレー、白など）を使用

### 2. コンテンツ面
- **具体的な数値**: 「収益が20%向上」など、具体的な効果を示す
- **ユーザーの課題**: 「価格設定に時間がかかる」「競合との価格差がわからない」などの課題を明確に
- **解決策の提示**: 各課題に対する具体的な解決方法を提示
- **導入事例**: 実際のホテルでの導入事例や効果を紹介（可能であれば）
- **セキュリティ**: データの安全性やプライバシー保護について言及

### 3. 構成面
- **ヒーローセクション**: 一目で価値提案が伝わるキャッチコピーとビジュアル
- **機能紹介**: 各機能をわかりやすく説明（スクリーンショットやモックアップを使用）
- **ベネフィット**: 機能ではなく、ユーザーが得られる利益を強調
- **導入ステップ**: 簡単な導入プロセスを説明
- **CTA（Call to Action）**: 明確な行動喚起ボタンを配置（無料トライアル、お問い合わせなど）
- **FAQ**: よくある質問を用意して、不安を解消

### 4. 技術面
- **パフォーマンス**: ページの読み込み速度を最適化
- **SEO対策**: 検索エンジンで見つけやすくする
- **アクセシビリティ**: 誰でも使いやすい設計
- **ブラウザ対応**: 主要ブラウザで正常に動作すること

### 5. コンバージョン最適化
- **社会的証明**: 導入実績、お客様の声、ロゴなどを掲載
- **緊急性**: 限定オファーや早期導入特典など（適切な場合）
- **リスク軽減**: 無料トライアル、返金保証など
- **明確な価格**: 料金プランを明確に表示（または「お問い合わせ」）

## 🎯 追加のLP作成ヒント

### 効果的なキャッチコピーの例
- 「AIが導く、ホテル収益最大化の道」
- 「データで見える、最適な価格設定」
- 「競合分析から価格最適化まで、すべて自動化」
- 「ホテル経営者のための、次世代収益管理システム」

### 強調すべきポイント
1. **時間の節約**: 「価格設定にかかる時間を90%削減」
2. **収益向上**: 「平均収益が20%向上した実績」
3. **精度の高さ**: 「AI予測の精度が95%以上」
4. **使いやすさ**: 「専門知識不要、直感的な操作」
5. **サポート**: 「専任サポートで安心導入」

### 避けるべきポイント
- 過度な技術用語の羅列（わかりやすさを優先）
- 曖昧な表現（具体的な数値や事例を使用）
- 長すぎる文章（簡潔で要点を押さえた文章）
- 信頼性の低い主張（根拠のない効果の宣伝）
