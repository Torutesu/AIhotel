# レベニュー知識ベース

ホテルレベニューマネジメントの知識・判断基準を、AIレベニュー管理システムが参照できる「ルールベース」として整備するディレクトリ。

| ファイル | 役割 |
|---|---|
| `tools/rules_data.py` | **単一ソース**。全ルール（ID・カテゴリ・種別・内容・推奨パラメータ・システム対応）と用語集 |
| `tools/build.py` | 上記から `レビューシート.xlsx` と `レベニュー知識ベース.md` を生成 |
| `レベニュー知識ベース.md` | 生成物。ルールベース形式の知識ベース（AIコメント生成・説明・Q&Aの根拠） |
| `レビューシート.xlsx` | 生成物。経験者に配布し、各ルールを「問題なし / 修正あり＋コメント」でチェックしてもらう |

## 運用

1. ルールの追加・修正は `tools/rules_data.py` を編集する（MD/xlsx を直接編集しない）
2. `cd tools && python build.py`（要 `pip install openpyxl`）で生成物を更新
3. レビューシートの回答を回収したら、ID（例 `E-06`）をキーに集計し、データ側に反映して再生成

## 実装値との関係

「推奨パラメータ」は汎用的な初期値の提案。実際の閾値・重み・補正値は、システム設定（`PricingStrategyConfig`・料金ランク・ホテル設定）およびコード（`backend/src/services/forecast/ruleBasedForecaster.ts` 等）が正。
本知識ベースは実装を**説明・検証・改善する根拠**として使い、実装値をここに転記しない。
