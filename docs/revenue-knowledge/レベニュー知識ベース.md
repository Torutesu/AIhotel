## 1. レベニューマネジメントとは

レベニューマネジメント（RM）は、**「適切な商品を、適切な顧客に、適切な価格で、適切なタイミング・チャネルで販売する」**ことで収益を最大化する経営手法。航空業界で生まれ、ホテルでは客室という「在庫の繰り越しができない商品」を扱うために発達した。

ホテルの客室には次の特性があり、これがRMの前提となる。

- **消滅性**: 今夜売れなかった客室は明日売れない。売り逃しはそのまま損失になる。
- **供給の固定性**: 需要が増えても客室数は増やせない。調整できるのは価格と販売条件のみ。
- **需要の変動性**: 季節・曜日・イベントで需要が大きく波打つ。
- **セグメントごとの支払意欲の差**: 同じ部屋でも、出張客・観光客・団体では払える金額も予約行動も違う。

RMの目的は「高く売ること」でも「満室にすること」でもなく、**両者の掛け算（RevPAR、ひいては利益）を最大化すること**。

## 2. 基本指標

| 指標 | 計算式 | 何を見る指標か |
|---|---|---|
| **OCC**（稼働率） | 販売客室数 ÷ 販売可能客室数 | 在庫がどれだけ売れたか |
| **ADR**（平均客室単価） | 客室売上 ÷ 販売客室数 | 1室あたりいくらで売れたか |
| **RevPAR** | 客室売上 ÷ 販売可能客室数（= OCC × ADR） | 稼働と単価を掛け合わせた総合力。RMの最重要指標 |
| **TRevPAR** | 総売上（料飲等含む）÷ 販売可能客室数 | 施設全体の稼ぐ力 |
| **GOPPAR** | 営業総利益 ÷ 販売可能客室数 | コストまで含めた収益性 |
| **ALOS**（平均泊数） | 延べ室数 ÷ 予約件数 | 連泊傾向。清掃コストや販売条件設計に影響 |
| **リードタイム** | 予約日から宿泊日までの日数 | 予約行動の早さ。セグメントごとに大きく異なる |

指標を読むときの原則:

- **OCCとADRは単独で評価しない。** 稼働率が高いだけなら「安売りしただけ」かもしれず、単価が高いだけなら「売り逃しただけ」かもしれない。必ずRevPARで総合評価する。
- **比較には必ず基準を置く。** 前年同期・予算・市場（競合）の3つと比べて初めて良し悪しが言える。
- **平均は日別・曜日別に分解する。** 月平均が順調でも特定の曜日や日付が崩れていることは多い。

## 3. 需要予測の考え方

需要は主に3つの波の重なりで動く。

1. **年間の季節性**: 繁忙期・閑散期。地域とホテルタイプで固有のパターンを持つ。
2. **週の曜日パターン**: ビジネスホテルは平日型、リゾート・観光地は週末型。過去実績と比較する際は「同じ曜日どうし」で比べるのが基本（平日と週末を混ぜない）。
3. **単発イベント**: コンサート、展示会、学会、スポーツ大会、花火大会など。需要を大きく押し上げるが、影響は当日だけでなく前後泊にも波及することがある。

予測の材料と注意点:

- **自館の過去実績が第一の材料。** 競合や市場データより、自館のブッキングカーブ・過去の同時期実績を優先する。
- **前年比較は暦のずれに注意。** 連休の位置、曜日のずれ、イベント日程の移動で前年の同日がそのまま参考にならないことがある。「前年の同じ日付」ではなく「前年の同じ位置づけの日（同曜日・同連休）」で比べる。
- **数字に表れない材料を持ち寄る。** 団体の内定・キャンセル、近隣の工事や催事、天候予報などは予約データより先に動く情報。
- **予測には必ず不確実性がある。** データが少ない日（新規開業直後、コロナ後のような断絶期）は予測の信頼度が下がることを前提に、幅を持って判断する。

## 4. ブッキングカーブとピックアップ

**ブッキングカーブ**は、ある宿泊日に向けて予約（OCC）がどう積み上がっていくかをリードタイム軸で描いた曲線。**ピックアップ**は、ある期間（例: 直近7日間）に積み上がった予約の増分。RMの日々の意思決定はほぼこの2つを見て行う。

基本の使い方:

- 宿泊日ごとに「目標カーブ（過去同等日の実績や予算から作る基準線）」を持ち、実際のカーブと比べる。
- **目標を上回るペース** → 需要が強い。値上げ・安値プランの停止・在庫の絞り込みを検討。
- **目標を下回るペース** → 原因を確認してから対応。競合の動き、イベントの有無、自館の露出（掲載順位・プラン内容）をチェックし、値下げは最後の手段にする。
- カーブの形はセグメントで違う。出張客は直前予約が多く、レジャーは早期予約が多い。インバウンドはさらにリードタイムが長い傾向。混ぜて見ると誤読する。

ピックアップを見る頻度は最低でも日次。繁忙日・イベント日は1日に複数回動くこともある。

## 5. 価格設定（ダイナミックプライシング）

需要の強さに応じて価格を上下させ、需要が強い日は単価を、弱い日は稼働を取りにいく。

原則:

- **繁忙日は「早く売り切らない」。** 安値で先に在庫を埋めると、高くても買った直前需要を取り逃がす（RMで最も典型的な損失）。繁忙日ほど段階的に価格を上げ、在庫を残しながら売る。
- **閑散日は値下げの前に条件を工夫する。** 単純値下げは単価とブランドを毀損しやすい。早期割・連泊プラン・朝食付きなどの条件付き価格や、販売チャネルの露出強化を先に検討する。
- **上限・下限を決めておく。** ブランド毀損を防ぐ下限価格と、機会損失を防ぐための上限の目安をあらかじめ設定し、その範囲内で動かす。
- **価格変更は理由とセットで記録する。** 「なぜ上げた/下げたか」が残っていないと、後から検証も学習もできない。
- **料金ランク制**（あらかじめ複数段階の料金表を作り、需要に応じてランクを切り替える方式）は、判断を速く一貫させる実務的な仕組みとして広く使われる。

価格を動かす判断材料の優先順位: ①自館のブッキングカーブ・ピックアップ → ②イベント・季節要因 → ③競合価格。競合は参考情報であり、追従が目的ではない。

## 6. 在庫コントロール

価格以外にも在庫の出し方で収益を調整できる。

- **泊数制限（Min LOS など）**: イベント日の前後で「2泊以上のみ受け付ける」等の制限をかけ、単泊で高需要日だけ埋まるのを防ぐ。
- **クローズアウト**: 特定チャネル・特定プランの販売を止める。繁忙日に手数料の高いチャネルや安値プランを閉じるのが典型。
- **部屋タイプ間の調整**: 安い部屋タイプから売れていくため、繁忙日は安いタイプを絞って上位タイプへ誘導（アップセル）する。
- **オーバーブッキング**: ノーショー・直前キャンセルを見込んで販売可能数を超えて受ける手法。実施する場合はノーショー率の実績に基づき、あふれた場合の対応（近隣への振替等）まで決めておく。

## 7. 販売チャネル戦略

日本のホテルの主な販売チャネルは、国内OTA（楽天トラベル、じゃらんnet、一休.com 等）、海外OTA（Booking.com、Agoda、Expedia 等）、自社公式サイト（直販）、電話・リアルエージェント、法人契約。

押さえるべき考え方:

- **チャネルには手数料差がある。** 国内主要OTAの実効手数料はポイント原資や決済手数料込みでおおむね1割強、海外OTAはそれ以上になることが多い。同じ価格で売れても、チャネルによって手残りが違う。
- **チャネルごとに客層が違う。** 国内ファミリー層は楽天・じゃらん、欧米インバウンドはBooking.com、アジア圏はAgoda、富裕層は一休・Relux が強い、といった傾向がある。自館のターゲットに合わせて注力チャネルを選ぶ。
- **レートパリティ（チャネル間の価格整合）**: 同一条件の部屋はチャネル間で価格を揃えるのが原則。ただし自社サイトには会員特典等の付加価値を付けて実質的に直販を優位にするのが一般的な戦略。
- **OTAは新規顧客の入口、直販はリピーターの受け皿**と位置づけ、直販比率を高めていくのが長期的な利益体質につながる（直販2割以上を一つの目安とする考え方がある）。
- **繁忙日ほど手残りの多いチャネルを優先**し、手数料の高いチャネルは閑散日の集客に使う。

## 8. 競合分析

- **コンプセット（比較対象の競合ホテル群）**は「立地・価格帯・客層が自館と重なる施設」で組む。有名だが客層の違う施設を入れると判断を誤る。
- 見るべきは競合の**価格そのものより「動き」**。競合が一斉に値上げしていれば市場需要が強いシグナル、1社だけ安いのはその施設固有の事情かもしれない。
- 競合の表示価格は、部屋タイプ・食事条件・キャンセルポリシーの違いを揃えて比べないと意味がない（最安値どうしの比較は条件がバラバラになりがち）。
- 市場全体のデータ（自治体・観光庁の統計、市場レポート等）と組み合わせ、「市場が伸びているのに自館が取れていない」のか「市場ごと縮んでいる」のかを切り分ける。

## 9. セグメント管理

需要は一枚岩ではなく、セグメントごとに価格感度・リードタイム・曜日パターンが違う。

| セグメント | 典型的な行動 | RM上のポイント |
|---|---|---|
| ビジネス個人 | 平日中心・直前予約・価格感度は中 | 平日の土台。直前まで在庫を残す価値がある |
| 国内レジャー | 週末・連休中心・比較検討が長い | 早期のプラン訴求が効く |
| インバウンド | リードタイムが長い・連泊傾向 | 早期に安値で埋めすぎない注意が特に必要 |
| 団体・グループ | 一括大口・キャンセルリスク大 | ベース需要として有難いが、繁忙日を安値で埋める諸刃の剣。個人需要の見込みと比較して受け入れ判断 |
| 法人契約 | 年間固定価格・平日安定 | 稼働の土台。ただし繁忙日の機会損失要因にもなる |

団体・法人の受け入れ判断では**ディスプレイスメント分析**（その予約を受けることで押し出される個人需要の売上と比較する）の考え方を使う。

## 10. 業務サイクル

**日次**
1. 前日実績（OCC・ADR・RevPAR）を予算・前年と比較
2. 今後60〜90日の日別ピックアップを確認、動きの速い日・遅い日を抽出
3. 抽出した日の原因を確認（イベント、競合、露出）し、価格・在庫を調整
4. 変更内容と理由を記録

**週次**
- 週間フォーキャスト（着地見込み）の更新と予算差の把握
- 競合価格・市場イベント情報の棚卸し
- 販売中プラン・チャネル別実績のレビュー

**月次**
- 月次着地の確定と要因分析（価格・稼働・セグメント・チャネル別）
- 翌月〜四半期の需要予測と価格方針の見直し
- 予算差が大きい場合のリカバリー策の立案

## 11. 判断の経験則集

- 稼働の読みが高く単価が低い日は、値上げ余地が大きい典型パターン。逆（単価は高いが稼働が読めない日)は値下げより販売条件・露出の見直しを先に。
- ピックアップが急に速くなったら、まず原因を探す。イベントの発生や競合の売止めなど、さらに強気にできる材料が見つかることが多い。
- 値上げは小刻みに何度でも。1回で大きく上げるより、売れ行きを見ながら段階的に上げる方が取りこぼしが少ない。
- 値下げの効果は「予約が入るか」ではなく「RevPARが上がるか」で測る。値下げで稼働が上がっても掛け算で負けていれば失敗。
- 直前の値下げが常態化するとゲストが学習し、早期予約が減る（自らブッキングカーブを壊す）。
- 繁忙日の残り数室は最も価値が高い在庫。最後まで強気を維持する。
- キャンセルポリシーの境界日（無料キャンセル期限）前後で予約とキャンセルが動く。見かけのピックアップに惑わされない。

## 12. よくある失敗と対策

| 失敗 | 何が起きるか | 対策 |
|---|---|---|
| 早売りしすぎ | 繁忙日を安値で先に埋め、直前の高単価需要を逃す | 繁忙日ほど段階的に値上げし在庫を残す |
| 直前の投げ売り | ゲストが「待てば安くなる」と学習、早期予約が減る | 値下げより条件・チャネルの工夫を先に |
| 競合追従しすぎ | 値下げ合戦になり市場全体の単価を毀損 | 自館の需要が強ければ追従しない |
| 平均値の罠 | 月平均は順調でも特定曜日・日付が崩れている | 日別・曜日別に分解して見る |
| 記録を残さない | 価格変更の検証・引き継ぎができない | 変更は理由とセットで記録 |
| 予測の過信 | イレギュラー時に大外れ | 確信度が低い予測は幅を持って扱い、直前修正の余地を残す |

## 13. 予算・着地見込み管理

- **フォーキャスト（着地見込み）**は「現時点の予約 ＋ 今後のピックアップ見込み」で月の着地を予測すること。予算との差を早期に把握し、間に合ううちに手を打つのが目的。
- 着地見込みと予算の差は「価格要因（ADR差）」と「数量要因（OCC差）」に分解すると打ち手につながる。
- 見込みが未達の場合の打ち手は残りリードタイムで変わる。残り日数が多ければプラン・露出の強化、少なければ直前需要の取り込み（ただし投げ売りは避ける）。

## 14. 説明・報告の言い回し

オーナー・支配人への説明は「結論 → 根拠 → 提案」の順で短く。専門用語には一言の補足を付ける。

- 悪い例: 「RevPARが前年比92%でOCCドリブンの下落です」
- 良い例: 「客室収益の効率を示すRevPARが前年より8%下がっています。単価は維持できており、主因は稼働率の低下です。○日と○日の平日について、値下げではなく連泊プランでのテコ入れを提案します」

数字の報告には必ず「比較対象（前年・予算・市場）」と「次のアクション」を添える。数字だけの報告は判断材料にならない。
