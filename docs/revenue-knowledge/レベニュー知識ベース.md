## 1. レベニューマネジメントとは

レベニューマネジメント（RM）は、**「適切な商品を、適切な顧客に、適切な価格で、適切なタイミング・チャネルで販売する」**ことで収益を最大化する経営手法。航空業界で生まれ、ホテルでは「在庫を繰り越せない商品＝客室」を扱うために発達した。

前提となる客室の4つの特性:

- **消滅性**: 今夜売れなかった客室は明日売れない。売り逃しはそのまま損失。
- **供給の固定性**: 需要が増えても客室数は増やせない。調整できるのは価格と販売条件のみ。
- **需要の変動性**: 季節・曜日・イベントで需要が大きく波打つ。
- **支払意欲の差**: 同じ部屋でも出張客・観光客・団体では払える金額も予約行動も違う。

RMが動かせる4つのレバー:

| レバー | 具体例 |
|---|---|
| 価格 | 日別価格の上げ下げ、料金ランクの切り替え、プラン別価格差 |
| 在庫・販売条件 | 泊数制限、チャネル・プランの売止め、部屋タイプ別の出し分け |
| チャネル | どの販売経路にどの価格・在庫を出すか、手数料を考慮した配分 |
| 商品（プラン） | 早割・連泊・朝食付き・キャンセル条件などのプラン設計 |

RMの目的は「高く売ること」でも「満室にすること」でもなく、**両者の掛け算（RevPAR、最終的には利益）の最大化**。RMは一人で完結せず、予約・フロント・営業・マーケとの情報共有で初めて機能する。

## 2. 基本指標

| 指標 | 計算式 | 何を見るか |
|---|---|---|
| OCC（稼働率） | 販売客室数 ÷ 販売可能客室数 | 在庫がどれだけ売れたか |
| ADR（平均客室単価） | 客室売上 ÷ 販売客室数 | 1室あたりいくらで売れたか |
| RevPAR | 客室売上 ÷ 販売可能客室数（= OCC × ADR） | 稼働×単価の総合力。RMの最重要指標 |
| TRevPAR | 総売上（料飲等含む）÷ 販売可能客室数 | 施設全体の稼ぐ力 |
| GOPPAR | 営業総利益 ÷ 販売可能客室数 | コストまで含めた収益性 |
| ALOS（平均泊数） | 延べ室数 ÷ 予約件数 | 連泊傾向 |
| リードタイム | 予約日 → 宿泊日の日数 | 予約行動の早さ。セグメントで大きく異なる |

計算例: 100室のホテルで80室が売れ客室売上96万円 → OCC 80%、ADR 12,000円、RevPAR 9,600円（= 80% × 12,000円）。

**ネット指標**: OTA手数料を引いたネットADR・ネットRevPARで見ると、チャネルごとの本当の手残りが比較できる。チャネル別の実績評価はネットで行う。

**市場と比べる指標（インデックス）**:

| 指標 | 計算式 | 意味 |
|---|---|---|
| MPI | 自館OCC ÷ コンプセット平均OCC × 100 | 100超なら市場より稼働が取れている |
| ARI | 自館ADR ÷ コンプセット平均ADR × 100 | 100超なら市場より高く売れている |
| RGI | 自館RevPAR ÷ コンプセット平均RevPAR × 100 | 市場シェアの総合評価。RM成績の通信簿 |

指標を読む3原則:

- **OCCとADRは単独で評価しない。** 必ずRevPARで総合評価する。
- **比較には基準を3つ置く。** 前年同期・予算・市場（コンプセット）。
- **平均は分解する。** 日別・曜日別・セグメント別に割って見る。

## 3. 需要予測の考え方

需要は主に3つの波の重なりで動く: **①年間の季節性 ②週の曜日パターン ③単発イベント**。ビジネスホテルは平日型、リゾート・観光地は週末型。過去実績との比較は「同じ曜日どうし」が基本。

日本の年間需要カレンダー（全国的な一般傾向の目安）:

| 時期 | 需要の動き |
|---|---|
| 正月〜1月中旬 | 年始は観光地が強い。成人の日連休のあと閑散期入り |
| 2月 | 年間で最も弱い時期のひとつ。受験・春節インバウンドが下支えする地域も |
| 3月下旬〜4月上旬 | 春休み・花見・年度替わりの移動需要で急回復 |
| GW | 年間最大級のピーク。中日の谷に注意 |
| 5月中旬〜6月 | 反動で弱含み。梅雨は観光地に逆風、ビジネスは安定 |
| 7月下旬〜8月 | 夏休み・お盆ピーク。お盆はビジネス需要が消えるため都市型は要注意 |
| 9月 | シルバーウィークの並び次第で変動 |
| 10月〜11月 | 行楽・紅葉・学会/展示会シーズン。都市型・観光型とも強い |
| 12月 | 忘年会・クリスマスは強いが下旬平日は弱い。年末年始は観光地ピーク |

これに**自館の商圏カレンダー（地元の祭事、展示会場・球場・ホールの日程）を重ねて初めて使える**。

予測の材料と注意点:

- **自館の過去実績が第一の材料。** 市場データや競合より自館のブッキングカーブ・過去同等日実績を優先。
- **前年比較は暦のずれを補正する。** 「前年の同じ日付」ではなく「前年の同じ位置づけの日（同曜日・同連休の並び）」と比べる。
- **満室日の実績は本当の需要を過小に見せる**（制約された需要）。満室で断った分は記録に残らないため、翌年は「前年実績＋α」で強気に読む。
- **数字より先に動く情報を拾う。** 団体の内定・キャンセル、近隣催事、交通の増減、天候。営業・フロントとの共有ルートを持つ。
- **予測には必ず不確実性がある。** データが少ない日は信頼度が下がる前提で幅を持って判断する。

## 4. ブッキングカーブとピックアップ

**OTB（On The Books）**＝現時点で帳簿に載っている予約数。**ブッキングカーブ**＝宿泊日に向けてOTBが積み上がる曲線。**ピックアップ**＝一定期間に積み上がった予約の増分。

基本動作:

1. 宿泊日ごとに**目標カーブ**（過去2〜3年の同等日実績や予算から作る基準線）を持つ。
2. 上回るペースなら値上げ・安値プラン停止・在庫絞り込みを検討。
3. 下回るペースなら**値下げの前に原因を確認**（競合、イベント、露出）。値下げは最後の手段。

リードタイム帯別の見方（都市型ホテルの目安）:

| リードタイム | 見るべきこと・打ち手 |
|---|---|
| 90〜60日前 | ベース作り。団体・法人ブロックの妥当性確認、イベント日の把握と初期価格設定。早期予約の入り方で強弱の兆しを掴む |
| 60〜30日前 | レジャー需要の主戦場。目標カーブとの乖離を週次確認、強い日は段階的値上げ開始 |
| 30〜14日前 | 方向性の確定期。強い日は泊数制限・チャネル絞りを併用。弱い日は原因特定（値下げはまだ早い） |
| 14〜7日前 | ビジネス需要が入り始める。ピックアップ速度を日次監視、価格を小刻みに調整 |
| 7日前〜当日 | 直前需要の刈り取り。残室少なければ最後まで強気。多ければ直前プラン活用（投げ売り回避）。キャンセル期限通過後の戻り在庫に即応 |

**ペース分析**: 「今日時点のOTB」は過去の**同じリードタイム時点のOTB**と比べる。着地実績と比べてもペースは判断できない。

**セグメントでカーブは違う**: 出張客は直前（0〜7日）、国内レジャーは2週間〜2か月前、インバウンドは数か月前から。混ぜて一本のカーブで見ると誤読する。

キャンセル期限の前後では予約とキャンセルが集中して動く。ネットの動き（新規−キャンセル）で見る。

## 5. 価格設定（ダイナミックプライシング）

判断材料の優先順位は **①自館のOTB・ピックアップ → ②イベント・季節要因 → ③競合価格**。競合は参考情報であり追従が目的ではない。

価格判断の基本マトリクス:

| OTB vs 目標 | リードタイムに余裕あり | 直前（〜7日） |
|---|---|---|
| 大幅に上回る | しっかり値上げ＋安値プラン停止＋泊数制限 | 強気を維持。残室は最高値クラスで |
| やや上回る | 小刻みに値上げし反応を見る | 維持〜小幅値上げ |
| 想定どおり | 維持。競合・イベントの変化だけ監視 | 維持 |
| やや下回る | 原因確認 → 露出・プラン強化。価格は維持 | 直前プラン・当日販売チャネル活用 |
| 大幅に下回る | 原因特定の上で価格・条件見直し。下限は死守 | 限定的な値下げ。常態化させない |

実務の原則:

- **繁忙日は「早く売り切らない」。** 繁忙日ほど段階的に価格を上げ、在庫を残しながら売る。
- **値上げは小刻みに何度でも。** 反応を見ながら段階的に。
- **閑散日は値下げの前に条件を工夫する。** 早割・連泊・朝食付き・返金不可などの条件付き価格、露出強化を先に。
- **上限・下限を決めておく。** 範囲内で動かす。
- **価格変更は理由とセットで記録する。**

レートフェンス（条件による価格の仕切り）:

| フェンス | 狙い |
|---|---|
| 早期予約割引（返金不可とセットが定石） | 早期のレジャー客を確保しつつ直前の高単価枠を守る |
| 返金不可 vs キャンセル可の価格差 | キャンセルリスクを価格に転嫁 |
| 連泊条件 | 閑散日を繁忙日に抱き合わせて埋める |
| 会員価格・直販限定特典 | パリティを保ちつつ直販を実質優位に |

**料金ランク制**: 複数段階の料金表を需要に応じて切り替える方式。判断が速く一貫し、記録・検証もしやすい。刻み幅は1段の変更が心理的ハードルにならない程度に細かく。端数価格の効果は価格帯により、高級帯ではキリの良い価格が好まれる傾向。

## 6. 在庫コントロール

| 手法 | 内容 | 典型的な使いどころ |
|---|---|---|
| Min LOS（最低泊数制限） | 「2泊以上のみ受付」等 | イベント日が単泊で埋まり前後泊を逃すのを防ぐ |
| CTA（到着日クローズ） | その日をイン日とする予約を止める | 超繁忙日は連泊の中日としてだけ売る |
| CTD（出発日クローズ） | その日をアウト日とする予約を止める | オペレーション集中の緩和等 |
| クローズアウト（売止め） | 特定チャネル・プランの販売停止 | 繁忙日に高手数料チャネル・安値プランを閉じる |
| 部屋タイプ出し分け | 安いタイプを絞り上位へ誘導 | 安い部屋から売れるため繁忙日はアップセルの好機 |

**オーバーブッキング**: 実施するなら曜日・セグメント別のノーショー率実績に基づいて上限を決め、あふれた場合の対応（振替先、差額負担、謝罪の段取り）まで事前に決める。体制がないまま行うのはブランド毀損リスクの方が大きい。

## 7. 販売チャネル戦略

**実効コストの把握**: OTAのコストは基本手数料＋ポイント原資＋事前決済手数料＋OTA内広告費の合計（実効手数料）で見る。国内主要OTAでおおむね1割強、海外OTAはそれ以上になることが多い。チャネル別評価はネットADR・ネットRevPARで。

チャネルごとの客層（一般的傾向）:

| チャネル | 強い客層 |
|---|---|
| 楽天トラベル・じゃらんnet | 国内レジャー・ファミリー層 |
| Booking.com | 欧米インバウンド、個人旅行 |
| Agoda | アジア圏インバウンド |
| 一休.com・Relux | 国内富裕層・記念日需要 |
| 自社公式サイト（直販） | リピーター・会員。手数料最軽 |
| 法人契約・リアルエージェント | 出張ベース需要・団体 |

戦略の定石:

- **OTAは新規顧客の入口、直販はリピーターの受け皿。** 直販比率2割以上を一つの目安とする考え方がある。
- **レートパリティが原則。** その上で自社サイトに会員価格・特典・ベストレート保証を付けて実質優位に。パリティが崩れるとOTA掲載順位低下・客の不信につながる。
- **繁忙日ほど手残りの多いチャネルを優先**し、高手数料チャネルは閑散日の集客に使う。
- **サイトコントローラー**の設定ミスは売り逃し・過剰販売に直結。定期点検する。

## 8. 競合分析

**コンプセットの組み方**: 立地・価格帯・客層が自館と重なる4〜6施設。「自館を検討する客が同時に比較している施設」が本来の競合。市場が変わったら組み直す。

**見るのは価格そのものより「動き」**:

- 競合が一斉に値上げ → 市場需要が強いシグナル。自館の強気を後押し。
- 1社だけ安い → その施設固有の事情の可能性。追従しない。
- 競合の売止め（満室）→ 流入が来る前提で値上げ余地を検討。

**価格比較の注意**: 部屋タイプ・食事条件・キャンセルポリシー・人数条件を揃えて比べる。定点観測は条件を固定して行う。

RGI計算例: 自館RevPAR 9,600円 ÷ コンプセット平均8,000円 × 100 = 120 → 市場平均より2割多く取れている。100を下回り続けるなら価格・商品・露出のどこかに構造課題。

市場全体のデータと組み合わせ、「市場が伸びているのに自館が取れていない」のか「市場ごと縮んでいる」のかを切り分ける。打ち手が全く違う。

## 9. セグメント管理

セグメント（客層の軸）とチャネル（販売経路の軸）は別物。「楽天経由」はチャネルであってセグメントではない。

| セグメント | 典型的な行動 | RM上のポイント |
|---|---|---|
| ビジネス個人 | 平日中心・直前予約・価格感度中 | 平日の土台。直前まで在庫を残す価値がある |
| 国内レジャー | 週末・連休中心・比較検討が長い | 早期のプラン訴求が効く |
| インバウンド | リードタイム長・連泊傾向・為替影響 | 早期に安値で埋めすぎない注意が特に必要 |
| 団体・グループ | 一括大口・キャンセルリスク大 | 繁忙日を安値で埋める諸刃の剣 |
| 法人契約 | 年間固定価格・平日安定 | 稼働の土台。繁忙日の機会損失要因にもなる |

**ディスプレイスメント分析**: 大口予約は、押し出される個人需要の売上と比較して受け入れを決める。
計算例: 残在庫30室の日に30室×8,000円=24万円の団体打診。個人販売なら20室×13,000円=26万円の見込み（確度高）なら、断る方が得（26万円＋残10室の追加販売）。個人の見込みが弱い閑散日なら同じ団体でも受ける。**その日の個人需要の強さで受け入れ可否と提示価格を変える**のが本質。

**ミックスの設計**: 月・季節単位で「どのセグメントで何割埋めるか」の設計を持ち、閑散期は団体・法人を厚く、繁忙期は個人・高単価の比率を上げる。実績と計画の差は月次で振り返る。

## 10. 業務サイクル

**日次（朝のルーティン）**:

1. 前日実績（OCC・ADR・RevPAR）を予算・前年・目標カーブと比較
2. 昨夜のピックアップ（新規−キャンセルのネット）を今後60〜90日分確認
3. 動きが想定と違う日を抽出し原因確認（イベント、競合、露出、キャンセル期限）
4. 価格・在庫・プランを調整
5. 変更内容と理由を記録
6. フロント・予約へ直近の方針を共有（残室の売り方、アップセル、ウォークイン価格）

**週次（RM会議の標準アジェンダ）**:

1. 週間実績レビューと月間フォーキャスト更新・予算差確認
2. 今後90日の要注意日（強い日・弱い日）の対策決定
3. 競合価格・市場イベント情報の棚卸し
4. プラン・チャネル別実績（ネットベース）のレビュー
5. 団体・法人案件の受け入れ判断（ディスプレイスメント確認）

**月次**:

- 月次着地の確定と要因分解（ADR要因×OCC要因、セグメント別・チャネル別）
- フォーキャスト精度の検証（何日前時点の見込みがどれだけ外れたか）
- 翌月〜四半期の需要見通しと価格方針・ミックス計画の見直し
- 予算差が大きい場合のリカバリー策立案

## 11. 判断の経験則集

- 稼働の読みが高く単価が低い日は、値上げ余地が大きい典型パターン。逆は値下げより販売条件・露出の見直しを先に。
- ピックアップが急に速くなったら、値上げの前にまず原因を探す。さらに強気にできる材料が見つかることが多い。
- 値上げは小刻みに何度でも。段階的に上げる方が取りこぼしが少ない。
- 値下げの効果は「予約が入るか」ではなく「RevPARが上がるか」で測る。
- 直前の値下げが常態化するとゲストが学習し、早期予約が減る（自らブッキングカーブを壊す）。
- 繁忙日の残り数室は最も価値が高い在庫。最後まで強気を維持する。
- キャンセル期限の前後は見かけの予約数が大きく動く。ネットの動きで判断する。
- 満室で断った需要は記録に残らない。満室日の翌年は「前年実績＋α」で強気に読む。
- 団体の相場観は「その日の個人需要の強さ」で毎回変える。年間一律の団体料金は繁忙日で損をする。
- イベント需要は当日より前後泊・周辺エリアに波及する。商圏全体の在庫が減れば追い風。
- 閑散日のテコ入れは「露出 → 条件 → 価格」の順で検討する。
- 週末が強い施設ほど、日曜泊（週末価格と平日価格の境目）の設定が収益差を生みやすい。

## 12. よくある失敗と対策

| 失敗 | 何が起きるか | 対策 |
|---|---|---|
| 早売りしすぎ | 繁忙日を安値で先に埋め、直前の高単価需要を逃す | 繁忙日ほど段階的に値上げし在庫を残す |
| 直前の投げ売り | 「待てば安くなる」と学習され早期予約が減る | 値下げより条件・チャネルの工夫を先に |
| 競合追従しすぎ | 値下げ合戦で市場全体の単価を毀損 | 自館の需要が強ければ追従しない |
| 平均値の罠 | 月平均は順調でも特定曜日・日付が崩れている | 日別・曜日別・セグメント別に分解 |
| イベントの見落とし | 需要急騰日を通常価格で売り切る | 商圏イベントカレンダーを常時更新する体制 |
| レートパリティ崩壊 | 価格不整合で掲載順位低下・客の不信 | サイトコントローラーの連動設定を定期点検 |
| 部屋タイプ放置 | 安いタイプだけ完売し上位タイプが余る | タイプ間価格差の調整、アップセル導線 |
| 記録を残さない | 検証・引き継ぎができない | 変更は理由とセットで記録 |
| 予測の過信 | イレギュラー時に大外れ | 低確信度の予測は幅を持って扱い直前修正の余地を残す |

## 13. フォーキャスト（着地見込み）

「現時点のOTB ＋ 今後のピックアップ見込み」で月の着地を予測する。**目的は当てることではなく、予算との差を早期に把握して間に合ううちに手を打つこと**。

積み上げの基本:

1. 日別に現在のOTB（室数・売上）を並べる。
2. 過去実績から「同じリードタイム時点のOTB → 着地」の伸び方（ピックアップ率）を曜日・時期別に求める。
3. 各日のOTBに伸び率を掛けて日別着地を見積もり、月で合算。イベント日・特異日は個別補正。

運用の要点:

- **予算差はADR要因とOCC要因に分解する。** 打ち手が全く違う。
- 未達見込みの打ち手は残りリードタイムで変わる。残り多ければプラン・露出強化、少なければ直前需要の取り込み（投げ売りは避ける）。
- **フォーキャスト精度を毎月検証する**（30日前・14日前時点の見込みと実績の差）。外れ方の癖を把握すると次から補正できる。
- 料飲・宴会・人員配置・仕入れもフォーキャストを使う。見込み精度は施設全体のコストに効く。

## 14. 説明・報告の言い回し

「結論 → 根拠 → 提案」の順で短く。専門用語には一言の補足。数字の報告には必ず「比較対象（前年・予算・市場）」と「次のアクション」を添える。

**業績下落の報告**
悪い例:「RevPARが前年比92%でOCCドリブンの下落です」
良い例:「客室収益の効率を示すRevPARが前年より8%下がっています。単価は維持できており、主因は稼働率の低下です。○日と○日の平日について、値下げではなく連泊プランでのテコ入れを提案します」

**値上げの提案**
悪い例:「○日はピックアップが強いので値上げします」
良い例:「○日は3週間前時点で例年より予約が2割速く入っています。近隣で△△（イベント）があるためです。現在の価格のままでは早く売り切れて機会損失になるので、本日から2段階の値上げを提案します。売れ行きが鈍ればすぐ戻します」

**団体受け入れの判断**
悪い例:「この団体は単価が安いのでお断りしました」
良い例:「○日の団体30室のお話は、個人のお客様で20室をより高い単価で販売できる見込みが高いため、提示価格では売上がむしろ減ると判断しお断りしました。同じ団体でも閑散日ならお受けする水準です」

| Min LOS / 泊数制限 | 最低宿泊数の制限 |
