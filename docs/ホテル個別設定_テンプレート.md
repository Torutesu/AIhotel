# ホテル個別設定 — 〈施設名〉

このファイルを施設ごとに複製して使う（例: `docs/hotels/新宿ワシントン.md`）。
共通仕様は `docs/レベニュー運用仕様_汎用.md`。**ここには汎用と違う値だけを書く。**

記入方法: ヒアリングシート（`docs/ホテル個別設定ヒアリングシート.xlsx`）の回答を転記する。
シートの設問ID（P-01 等）とこのファイルの「設問」列は対応している。

| | |
|---|---|
| 施設名 | |
| 施設コード | |
| 記入者 / 記入日 | |
| ヒアリング実施日 | |
| 版 | v0.1（下書き） |
| 適用開始 | |

**凡例** — `（既定）` = 汎用の既定値をそのまま使う ／ `未確認` = ヒアリング未了 ／
`保留` = 協議アジェンダの決定待ち

## 6. 価格運用ポリシー

> **V-01 は最優先。** 「売上は上がらなくても高単価の客を取る」「前の日より安く売らない」
> といった方針は施設ごとに異なり、推奨の出し方そのものが変わる。

| 項目 | 汎用既定値 | この施設 | 設問 |

| 方針の補足 | — | | V-02 |
| 戦略の重み（稼働 / ADR / 競合） | 40 / 40 / 20 | / / （計100%） | V-03〜05 |
| 1日あたりの変更幅上限 | 3ランク | | V-06 |
| 上げ下げの非対称 | 上げ+2 / 下げ−1 | | V-07 |
| 最小変更単位 | 1ランク | | V-08 |
| 変更頻度の上限 | 1回/日（直前7日は2回） | | V-09 |
| 繁忙日の段階値上げの節目 | OCC 50 / 70 / 85% | | V-10 |

| 直前値下げの可否 | 条件付き | | V-12 |

> 需要レベルの閾値は汎用MDでは「A〜Eの5段階」としか定義していない。
