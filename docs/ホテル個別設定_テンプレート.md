# ホテル個別設定 — 〈施設名〉

このファイルを施設ごとに複製して使う（例: `docs/hotels/新宿ワシントン.md`）。
共通仕様は `docs/レベニュー運用仕様_汎用.md`。**ここには汎用と違う値だけを書く。**

記入方法: ヒアリングシート（`ホテル個別設定ヒアリングシート.xlsx`）の回答を転記する。
シートのID（A-01 等）とこのファイルの「出典」列は対応している。

| 施設名 | |
| 施設コード | |
| 記入者 / 記入日 | |
| ヒアリング実施日 | |
| 版 | v0.1（下書き） |

**凡例** — `（既定）` = 汎用の既定値をそのまま使う ／ `未確認` = ヒアリング未了 ／
`保留` = 協議アジェンダの決定待ち
