# 運営管理画面

`/operations` に運営専用UIを配置。顧客向け設定にはテナント・トライアル管理を表示しない。

- 専用環境の `NEXT_PUBLIC_DEMO_ADMIN_CONSOLE=true` のときのみルートを提供。それ以外は404。
- ログイン後の `PLATFORM_ADMIN` だけがコンソールを使用できる。他ロールではデータ取得も開始しない。
- 実APIの `/platform/*` は既存の authenticate / requireRole('PLATFORM_ADMIN') を維持。
- デモのトライアルAPIは専用環境フラグと、サーバー検証する運営セッションCookieの両方が必要。
- 運営ログイン後はホテル画面から `/operations` へ移動。

概要・顧客一覧・利用状況・トライアル管理をURLのsectionで切替。顧客・トライアル検索、未ログイン・期限間近の絞り込み、テーマ変更に対応。
スマホのトライアル一覧はカード状に表示。

## デモのデータ境界

デモ環境の顧客・ホテル情報はサンプル。トライアルの発行・延長・停止等は共有保存に反映する実操作。
利用状況はトライアルの最終ログインと状態・期限を表示する。操作回数・滞在時間・機能別の利用頻度は未集計で、UIにも明示。
